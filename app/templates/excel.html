2 · Edit in Excel

Change dates, clubs, cities, or stakes right in the spreadsheet. The downloaded file has an EVENT ID column — leave it alone and your edits will update those same events. Rows you add without an ID become new events. Judges, fees, and links aren't in the spreadsheet — edit those on the event page.

Making next year's schedule from this year's? Download this year, change the dates to next year, then tick the box below when uploading so every row is treated as a new event. (The Roll a season forward page does the same thing without Excel.)
